# L'Eau de Là · Liqueurs

Appli Android hors ligne de L'Eau de Là : calcul des liqueurs (alcool, eau, sucre, contraction), recettes,
stock des produits finis, consommables, ventes (espèces ou carte via SumUp), graphiques et
synchronisation directe entre appareils (Bluetooth / Wi-Fi direct).

La mise en page s'adapte à l'écran : rail d'onglets et deux colonnes sur tablette à l'horizontale
(Crosscall Core-T4), mise en page téléphone en portrait et sur les smartphones.

Chaque push sur `main` compile l'APK (GitHub Actions) et le publie dans **Releases**.
